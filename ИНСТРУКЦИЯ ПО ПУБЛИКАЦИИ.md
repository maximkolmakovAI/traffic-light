# Инструкция по публикации на GitHub

## 1. Создать репозиторий на GitHub

1. Откройте https://github.com и войдите в аккаунт
2. Нажмите зелёную кнопку **New** (или `+` → `New repository`)
3. Название: `traffic-light` (или любое другое)
4. Описание: `Светофор по клиентской базе — анализ отчетов 1С`
5. Оставьте **Public** (чтобы клиент мог скачать)
6. **Не** ставьте галочки "Add a README", "Add .gitignore", "Choose a license"
7. Нажмите **Create repository**

## 2. Загрузить проект

После создания репозитория GitHub покажет команды. Скопируйте их по очереди.

Откройте **PowerShell** (не обычную cmd, а именно PowerShell) и выполните:

```powershell
# Перейти в папку проекта
cd C:\AI_ALL\Разработка 1С на OpenCode\Анализ отчетов для Вали\traffic_light

# Инициализировать Git (уже сделано — пропустите если ошибка)
git init

# Добавить все файлы
git add .

# Создать первый коммит
git commit -m "Первый релиз: светофор по клиентской базе"
```

Теперь свяжите с GitHub:
```powershell
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/traffic-light.git
git push -u origin main
```

*(замените `ВАШ_ЛОГИН` на свой логин GitHub)*

GitHub запросит логин/пароль — введите. Если включена двухфакторка, используйте **Personal Access Token** вместо пароля:
- https://github.com/settings/tokens → Generate new token → `repo` → скопировать токен
- Вставить токен вместо пароля при push

## 3. Что скачивает клиент

Клиент делает:
```powershell
git clone https://github.com/ВАШ_ЛОГИН/traffic-light.git
cd traffic-light
start.bat
```

Или просто скачивает ZIP с GitHub → распаковывает → запускает `start.bat`.

## 4. Важно: что НЕ попадает в репозиторий

Файлы ниже уже добавлены в `.gitignore`:
- `data/*.db` — база данных (клиент создаст свою при первом запуске)
- `.streamlit/` — локальные настройки Streamlit
- `.env` — ключи API (если создадите)
- `__pycache__/` — кеш Python

## 5. Файлы для передачи клиенту

Всё необходимое уже включено в коммит:
- `app.py`, `config.py`, `requirements.txt`
- `db/`, `etl/`, `engine/` — весь код
- `start.bat` — кнопка запуска
- `ИНСТРУКЦИЯ ПО ПУБЛИКАЦИИ.md` — этот файл (можно удалить перед отправкой)

Клиенту **не нужны** исходные файлы отчетов — их он будет загружать сам через интерфейс (когда появится функция загрузки).

## 6. Как обновить после изменений

```powershell
cd C:\AI_ALL\Разработка 1С на OpenCode\Анализ отчетов для Вали\traffic_light
git add .
git commit -m "Описание изменений"
git push
```

Клиент обновляет:
```powershell
cd traffic-light
git pull
```
