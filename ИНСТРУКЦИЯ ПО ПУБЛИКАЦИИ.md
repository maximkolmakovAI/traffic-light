# Инструкция: публикация на GitHub + Streamlit Cloud

## Шаг 1. Создать репозиторий на GitHub

1. https://github.com/new
2. Repository name: `traffic-light`
3. Public
4. **Не** ставить галочки (README, .gitignore, лицензия)
5. Create repository

## Шаг 2. Залить код

Открыть **PowerShell**, выполнить:

```powershell
cd C:\AI_ALL\Разработка 1С на OpenCode\Анализ отчетов для Вали\traffic_light

git remote add origin https://github.com/maximkolmakovAI/traffic-light.git
git push -u origin main
```

Если просит пароль — используйте Personal Access Token:
- https://github.com/settings/tokens → Generate new token → repo → создать
- Вставить token вместо пароля

## Шаг 3. Опубликовать на Streamlit Cloud (бесплатно)

1. Зайти на https://share.streamlit.io
2. Войти через GitHub
3. Нажать **New app**
4. Выбрать репозиторий `maximkolmakovAI/traffic-light`
5. Branch: `main`, Main file: `app.py`
6. Дополнительно → **Secrets**:
   ```
   AI_API_KEY = "sk-2dbPPD0-PWa-1GUgVfonjg"
   ```
7. **Deploy**

Через ~2 минуты приложение будет доступно по ссылке:
`https://traffic-light.streamlit.app/`

## Шаг 4. Ссылка для клиента

Клиенту отдаёте ссылку — он открывает в браузере, нажимает **«Полная загрузка (ETL)»**, потом **«Пересчитать светофор»**. Ничего устанавливать не нужно.

## Как обновить приложение

```powershell
cd C:\AI_ALL\Разработка 1С на OpenCode\Анализ отчетов для Вали\traffic_light
git add .
git commit -m "что изменили"
git push
```

Streamlit Cloud автоматически подхватит изменения (или нажать **Reboot** в дашборде).
